# DinnerGang Helper — releases

Release builds of **DinnerGang Helper**, a macOS menu-bar app for preparing DJ sets. The source code is private; this repo only hosts the zips that the app's **Settings › General › Check for Updates** downloads.

**Install:** download the latest `DinnerGang-Helper-<version>.zip` from [Releases](https://github.com/the-bridge-dev/DinnerGang-Helper-releases/releases), check its SHA-256 against the `.sha256` file, unzip, drag **DinnerGang Helper.app** to /Applications, then the first time right-click → Open (ad-hoc signed, not notarised). Apple Silicon, macOS 14 or later.
